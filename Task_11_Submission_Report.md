# Task 11 Submission Report
## Basic Data Sorting & Filtering

**Internship:** HI T – Data Analytics Track  
**Level / Day:** Level 1 / Day 11  
**Tools:** Microsoft Excel / Google Sheets

### Aim
To explore retail order data using sorting and filters and answer five basic business questions.

### Work completed
A 20-record practice dataset was prepared. The workbook separates the original records from sorted and filtered views. Sales were sorted from highest to lowest. A multiple-filter example was created for Technology orders in the West region.

### Business questions
1. Highest-sales region: West ($4,228.00).
2. Highest-sales category: Technology ($5,244.00).
3. Highest-sales product: Smartphone ($4,794.00).
4. Orders above $500: ORD-1001, ORD-1006, ORD-1011, ORD-1013, ORD-1016.
5. Consumer-segment order count: 8.

### Interview understanding
Filtering is preferred when records need to be temporarily hidden based on conditions without removing them. Raw data is preserved so that analysis can be checked, repeated and corrected without losing the original records.

### Conclusion
Sorting and filtering help turn a transaction list into useful business information. Multiple filters narrow the data to a specific business segment, while a separate raw-data sheet protects the original dataset.
